## 格式

```markdown
[${title}](${url}) - *${description}*
```

```markdown
${url} - *${title}*
```

### ${title}

从网页 `<title></title>` 中提取。

### ${url}

网址链接。

### ${description}

从网页 `<meta name="description" content="" / >` 中提取。

### ${details}

```markdown
<details markdown='1'><summary><i style="color:red">SEE MORE >></i></summary>

    ${content}

</details>
```

### ${icon}

```markdown
> <img src="" alt="package icon" loading="lazy" decoding="async" align="left" width="58" hspace="10" vspace="0" />
```

### ${platform}

- 操作系统 `${desktop}`
    - 支持 Windows, macOS, Linux
- 移动应用程序 `${mobile}`
    - 支持 Android, iOS
- 浏览器 `${web}`
    - 支持 Web, Web Browser Extensions
- 开发人员 `${developer}`
    - 支持 CLI
    - 支持 Server
- 集成 `${integrations}`
    - 支持 IDEs Plugin, Editors Plugin
    - 支持 Email Add-ons
- 其它 `${other}`

- 代码托管平台 `${hosting}`

    - GitLab
    - Self-hosting
